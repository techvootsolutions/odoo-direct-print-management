Feature Details

Configurations

Navigate to Printing > Configuration > Settings to configure global print behavior, enable QWeb PDF interception, and set default printer preferences.

OS Printer Setup

Configure your operating system's printer name inside Odoo so Direct Print Management can map the correct output device.

User Printer Configuration

Each user can select their default printer under Preferences or user settings, ensuring the correct printer is always selected per user.

Sale Order Print Preview

When printing a Sale Order, the preview dialog opens showing the actual PDF report. The browser print dialog is automatically triggered for immediate printing.

Sale Print Action

Trigger the print action from the Sale Order form. The module intercepts the QWeb PDF action and opens the preview instead of downloading the PDF directly.

Accounting Report Preview

Balance Sheet, Profit & Loss, and all accounting PDF exports are intercepted and shown in the print preview dialog.

Frequently Asked Questions

Common questions about installation, compatibility, and features

Does this module require Odoo Enterprise?
This module is compatible with both Odoo 19 Community and Enterprise. The account_reports dependency is available in both editions for Odoo 19. It also supports Odoo.sh deployments.
Which reports does it intercept?
It intercepts all standard QWeb PDF report actions globally across every Odoo module, including Sales, Invoices, Purchase Orders, and all accounting reports (Balance Sheet, P&L, etc.).
How does the auto browser print trigger work?
When the preview dialog opens, it automatically calls the browser's print function (equivalent to Ctrl+P). Users can still cancel or adjust print settings before confirming.
How do I configure a default printer for a user?
Go to Printing > Configuration > Printers, add the OS printer name, and assign it to a user or company. Each user can also set their own printer under their profile preferences.
Does it support multi-company setups?
Yes. Printer profiles can be isolated per company, ensuring the correct printer is used for each company's document outputs in multi-company environments.
Can I still download the PDF instead of printing?
Yes. The preview dialog includes a dedicated Download PDF button alongside the Print and Close buttons, giving users full control over the output.
